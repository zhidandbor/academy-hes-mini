# Миникурсы Высшей инженерной школы

[Открыть каталог миникурсов](https://zhidandbor.github.io/academy-hes-mini/) · [Главная библиотека Academy](https://zhidandbor.github.io/academy/) · [Основной репозиторий Academy](https://github.com/zhidandbor/academy) · [Основные курсы HES](https://zhidandbor.github.io/academy-hes/)

Этот репозиторий содержит публичные статические выпуски двух миникурсов, собранных в проекте HES:

| Миникурс | Уроки | Открыть |
| --- | ---: | --- |
| Как делегировать ИИ строительную рутину | 7 | [Страница курса](https://zhidandbor.github.io/academy-hes-mini/course_kak_delegirovat_ii_stroitelnuyu_rutinu/) |
| Как рассчитать объемы работ | 5 | [Страница курса](https://zhidandbor.github.io/academy-hes-mini/course_raschet_obemov_rabot/) |

Курсы находятся в `docs/<course>/`. В каждой папке есть `release.json` с ревизией исходного репозитория и составом выпуска. GitHub Pages публикует `main:/docs`; сайт и этот репозиторий доступны без регистрации.

Сохранённые страницы не воспроизводят личный кабинет, серверную проверку ответов и результаты тестов. У курса по расчёту объёмов работ 12 изображений были недоступны уже в источнике; у курса по делегированию ИИ часть зависимостей одного встроенного документа недоступна. Подробности находятся в исходных README и публичных манифестах.

Исходные снимки страниц, скрипты сборки и проверочные отчёты хранятся в приватном репозитории HES. Публикуемые страницы и ресурсы не следует редактировать вручную: новый выпуск собирается из проверенного источника.
