Памятка операционного контроля

Новый СП по стройконтролю строительства, реконструкции и капремонта ОКС

Что проверит стройконтроль при операционном контроле

  • Соблюдение требований охраны труда
  • Соответствие производственных операций нормативным документам и организационно-технологической документации
  • Соблюдение технологических режимов, установленных организационно-технологической документацией
  • Соответствие показателей качества выполнения операций и их результатов требованиям проектной и организационно-технологической документации

Какие параметры должны быть отражены в составе ОТД для качественного  операционного контроля 

  • Перечень операций или процессов, которые подлежат проверке по показателям качества
  • Чертежи конструкций с указанием допустимых отклонений
  • Места выполнения контроля, их частота, методы, исполнители, средства измерений и формы записи результатов. Они должны соответствовать требованиям нормативных документов, проектной и организационно-технологической документации
